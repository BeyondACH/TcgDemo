# TcgDemo UI 视觉规范 v2.0

更新时间：2026-06-08  
方向：独立数字面板 · Master Duel 冷蓝黑基底  
设计基准分辨率：2560×1440（1080p 降级适配）

---

## 1. 设计总述

### 1.1 方向定位

本规范定义 TcgDemo v2.0 的数字战场 UI 视觉基线。基本方向为"独立数字面板 + 赛博竞技场
氛围"，参考 Yu-Gi-Oh! Master Duel 的冷蓝黑基底与锐利面板语言。

核心体验目标：

- 四个主面板（敌能量 / 敌前线 / 我前线 / 我能线）是视觉一级公民，清晰独立
- 冷蓝黑基底压低背景噪声，青/金色做交互强调，暖红/冷蓝区分区域属性
- 面板半透明深底 + 锐利边框 + `StyleBoxFlat` 驱动，最大限度减少素材依赖
- 卫星区域退化为紧凑附属堆叠，不抢占主面板视觉权重
- 1440p 下卡牌 ~270×380px，1080p 下 ~180×250px

### 1.2 与 v1.0 的区别

| 维度 | v1.0（已弃用） | v2.0 |
|------|:---:|:---:|
| 视觉隐喻 | 实体卡店桌垫印刷分区 | 独立数字面板 + 赛博竞技场 |
| 区域关系 | 同一张垫子上的线框区域 | 四行独立面板模块 |
| 底色 | 暖红黑 (`#0F1115` + 红渐变) | 冷蓝黑 (`#0A0E17`) |
| 强调色 | `#C83A3A` 红 | `#00ACC1` 青 + `#D4A843` 暗金 |
| 区域定位 | 背景图比例映射 | Container 布局 + anchor |
| 卫星区 | 独立角落大面板 | 紧凑附属堆叠 |
| AP | AP 区域 3 槽 | 顶部 HUD 数字计数器 |
| 设计基准 | 1920×1080 | 2560×1440 |

## 4. 主面板规范

### 4.1 通用面板结构

一个主面板由以下部分组成（从上到下）：

```
┌─────────────────────────────────────┐
│  FRONT LINE · 3/4     [操作按钮]   │  ← 标题条 28px
├─────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌────┐ │
│  │ 槽1  │ │ 槽2  │ │ 槽3  │ │空槽│ │  ← 槽位行
│  └──────┘ └──────┘ └──────┘ └────┘ │
└─────────────────────────────────────┘
```

#### 通用样式

- 面板底色：`panel_bg` (`rgba(20, 26, 36, 0.88)`)
- 面板圆角：`14px`
- 面板边框：`1px solid rgba(210, 220, 235, 0.10)`
- 面板内边距：`12px`
- 面板阴影：`0 10px 28px rgba(0, 0, 0, 0.32)`
- 面板外发光（默认）：`0 0 18px rgba(0, 172, 193, 0.04)`

#### 标题条

- 高度：`28px`
- 圆角：`12px`（仅顶部两个角）
- 底色：面板深层面 `#10151D`（或前线用暖红底、能量线用冷蓝底）
- 标题文字：`700` 字重，`14px`，英文全大写，字距 `0.6px`
- 槽位计数：`400` 字重，`12px`，用 `·` 与标题分隔
- 右侧上下文按钮：按钮高度 `24px`，与标题条右边缘间距 `8px`

#### 槽位

见第 5 节。

### 4.2 前线面板（Front Line Panel）

- 标题底色：`accent_red` (`#A8454A`)，加 `8%` 透明度叠底
- 标题文字色：`#F5EBE8`
- 选中/交互高亮边框：`2px solid #00ACC1`
- 阻挡选择态边框：`2px solid #D4A843`，面板外发光增强至 `0 0 24px rgba(212, 168, 67, 0.16)`

### 4.3 能量线面板（Energy Line Panel）

- 标题底色：`accent_blue` (`#4A90D9`)，加 `8%` 透明度叠底
- 标题文字色：`#E8EFF7`
- 选中/交互高亮边框：`2px solid #00ACC1`
- 面板外发光（默认）：低强度，`0 0 12px rgba(74, 144, 217, 0.06)`

### 4.4 面板尺寸

以 2560×1440 为基准（1080p 下按比例缩放）：

- 面板左右边距：面板占视口宽度的 62%，两侧各留 19% 给预览面板和侧边空白
- 面板宽度 ≈ `1587px`（1440p） / `1190px`（1080p）
- 前线面板高度：前线占 4 面板总高度的 55%
- 能量线面板高度：占总高度 45%
- 面板间距（面板之间的垂直空隙）：`8px`

## 5. 槽位规范

### 5.1 基础槽位

- 槽位底色：`rgba(255, 255, 255, 0.02)`
- 槽位描边（默认空槽）：`1.5px dashed rgba(210, 220, 235, 0.14)`
- 圆角：`10px`
- 每面板 4 槽位，横向排列，槽间距 `14px`（1440p）/ `10px`（1080p）

### 5.2 空槽表达

- 中心标识：微弱区域图标（前线=剑 / 能量线=菱形），透明度 14%，尺寸 20×20px
- 禁止使用大号 "+" 或高亮虚线框
- 图标需从素材包引入（`assets/ui/icons/`），在素材就绪前可用 Unicode 占位或留空

### 5.3 悬停态

- 描边切换为 `1px solid #4DD0E1`
- 外发光：`0 0 10px rgba(0, 172, 193, 0.12)`

### 5.4 选中态

- 描边：`2px solid #00ACC1`
- 外发光：`0 0 16px rgba(0, 172, 193, 0.18)`

### 5.5 不可用态

- 槽位整体明度降低 16%
- 边框变为 `#232A33`

### 5.6 满员提示

- 面板标题条计数 `4/4` 时数字变红：`accent_red` (`#A8454A`)
- 满员面板不接受手牌拖拽落点（拖入时无高亮反馈）

## 7. 附属堆叠规范

### 7.1 通用堆叠样式

- 显示 3-4 张偏移微缩卡背，每张偏移 7px（1440p）/ 6px（1080p）
- 卡背尺寸：~42×58px（1440p）/ ~36×50px（1080p）
- 计数徽标：圆形，22px 直径（1440p）/ 18px（1080p），白色底 `#EDF0F5`、深文字 `#0A0E17`、居中
- 徽标位置：堆叠右上角上方偏移 4px
- 背景色：`rgba(20, 26, 36, 0.82)`
- 圆角：`10px`
- 点击弹出 `ZoneCardsPopup`

### 7.2 生命堆叠（Life Stack）

- 贴前线面板左侧外缘，与面板左边缘间距 `8px`
- 纵向居中于前线面板
- 敌方和我方各一个，贴各自前线面板左侧

### 7.3 牌库堆叠（Deck Stack）

- 贴前线面板右侧外缘，与面板右边缘间距 `8px`
- 纵向居中于前线面板

### 7.4 场外堆叠 / 移除堆叠

- 贴我能线面板右下角，纵向排列
- 比 LIFE/DECK 再小一号：卡背 ~34×48px、徽标 16px

## 8. 顶部 HUD

### 8.1 结构与内容

屏幕顶部 40px 高极简信息条。从左到右：

```
[回合3] [主要阶段]    [AP: 2/3]  [🔴1 🔵2 🟢0 🟣0 🟡1 ⚪0]
```

- 底色：`rgba(10, 14, 23, 0.90)`
- 下边框：`1px solid rgba(210, 220, 235, 0.06)`
- 水平内边距：`16px`
- 左右分布：回合/阶段靠左，AP 和能量靠右
- 不挂任何操作按钮

### 8.2 回合/阶段

- 回合数：`700` 字重，`14px`，`#EDF0F5`
- 阶段名：`400` 字重，`14px`，`#A8B2C2`

### 8.3 AP 计数器

- `AP: 2/3` 格式
- 可用数用 `#D4A843`，总数用 `#A8B2C2`
- 字重 `600`，`14px`

### 8.4 能量圆点

- 6 个颜色圆点，直径 14px，间距 6px
- 有效能量的颜色：红 `#D95A5A` / 蓝 `#4A90D9` / 绿 `#5C9A6E` / 紫 `#8E6BBF` / 黄 `#D4A843` / 白 `#D0D5DE`
- 无效能量的颜色：`#3D4553`（灰掉）
- 每个圆点旁或圆内写对应数字，`11px` `600` 字重
- 素材就绪前用 `StyleBoxFlat` + `ColorRect` 组合实现

## 9. 手牌区域

### 9.1 定位

- 屏幕底部，紧贴我能线面板下方
- 手牌条高度 ~140px（1440p）/ ~110px（1080p 紧凑模式）
- 手牌水平居中，按可用宽度自动计算张数和重叠量

### 9.2 手牌显示

- 卡牌尺寸：见 6.1 节
- 水平重叠：根据手牌数量和可用宽度自动计算
- 悬停时该卡牌微微上浮（`translate` y 方向 -8px）+ 描边切 `#4DD0E1`
- 当前选中手牌：描边 `2px solid #00ACC1`，上浮更明显（-12px）

### 9.3 拖拽

- 从手牌拖拽时，生成拖拽预览（半透明卡面，scale 0.9）
- 合法落点：前线面板、能量线面板（拖到整个面板区域，不限于槽位）
- 拖入合法面板时面板边框切 `#00ACC1`
- 满员面板（`4/4`）不接受拖拽——无高亮反馈
- 松手后卡牌飞入目标面板第一个空槽位

## 16. 动效规范

### 16.1 总体原则

- 动效服务于信息确认，不装饰
- 速度偏快、干净

### 16.2 时长

- 悬停淡入：`100ms`
- 选中强调：`140ms`
- 卡牌入场/离场：`180ms`
- 面板过渡：`160ms`
- Tooltip 延迟弹出：`400ms` 悬停后
- 日志抽屉滑入：`180ms`
- Inline 错误淡出：`2000ms`

### 16.3 三类分批

1. **必做：入场/离场/区域转移** — 卡牌登场飞入目标槽位、退场缩小淡出、手牌拖拽飞入面板
2. **高优：状态切换** — 休息旋转 90°、选中金/青色描边点亮、hover 上浮 + 描边增强
3. **低优：面板/弹窗过渡** — 弹窗缩放淡入、日志滑入、预览面板切换

第一批必须在新骨架上做钩子预留（`Tween` 入口点），后续补实现。

### 16.4 禁止

- 禁止大面积粒子、闪光、连续闪屏
- 禁止高频震动或长时间漂浮
- 禁止多个区域同时强脉冲

## 17. Theme 组织

### 17.1 单一 Theme

建一个 `res://assets/ui/battle_theme.theme`，挂到 `BattleScene` 根节点。

Theme 内容：
- default_font：Noto Sans SC（中文）+ Barlow Condensed（英文/数字，通过 fallback）
- 所有颜色常量映射到本节色板
- `StyleBoxFlat` 定义为 Theme 内置 StyleBox：`PanelStyle`、`ButtonPrimary`、`ButtonSecondary`、`SlotEmpty`、`SlotHover`、`SlotSelected`
- Type variation：`FrontCard`、`EnergyCard`、`HandCard`、`PopupCard`

### 17.2 覆盖原则

- `add_theme_*_override()` 仅用于少数必须动态计算的场景（响应式断点切换字号、面板颜色随上下文变化）
- 静态样式全部走 Theme 继承
- 素材版 `StyleBoxTexture` 替换入口预留：Theme 中定义 `SlotPlateTexture` 等键名，素材就绪后只换资源引用

## 18. 响应式断点

### 18.1 基准与档位

| 档位 | 分辨率 | 说明 |
| --- | --- | --- |
| 设计基准 | 2560×1440 | 所有尺寸按此定义 |
| 降级适配 | 1920×1080 | 卡牌/间距/字号按比例缩至 ~70% |
| 最小支持 | 1600×900 | 进一步缩，可能隐藏预览面板或合并附属堆叠 |

### 18.2 1080p 降级规则

- 全局缩放因子：`1080 / 1440 ≈ 0.75`（实际按可用面板高度精确计算）
- 手牌高度：140px → 110px
- 面板间距：8px → 6px
- 槽位间距：14px → 10px
- 字号层级各降 1-2px
- Aspect ratio 和布局结构不变

## 20. 最终原则

- 所有视觉决策以"面板清晰独立、操作就近、信息分层"为最高原则
- 前线面板和能量线面板是视觉一级公民，附属堆叠退居次要
- 冷蓝黑底压低背景噪声，青/金色承担全部交互反馈
- `StyleBoxFlat` 驱动为主、素材为辅，Theme 统一管理
- 动效分批做，不阻塞骨架和布局
- 任何新增 UI 元素必须落入本规范的色彩/间距/圆角/描边系统
