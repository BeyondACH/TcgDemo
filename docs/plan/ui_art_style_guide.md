# TcgDemo UI 美术风格规范

更新时间：2026-03-30

## 1. 设计总述

本规范用于统一 TcgDemo 的数字战场视觉语言，目标是建立一套可直接指导界面稿、图标制作、面板样式、卡槽样式与素材命名的正式 UI 美术基线。

整体方向定义为“竞技桌面感 + 数字卡牌界面感”，并以当前参考战场底图的红色竞技桌垫氛围作为视觉锚点。最终界面不是照搬印刷桌布，而是在保留该底图布局识别度、红黑气质与槽位秩序感的前提下，向更适合屏幕显示的数字 UI 收敛。

强调以下体验目标：

- 视觉氛围偏暗黑竞技，而不是展示型手游首页
- 主战场分区清晰，信息层级一眼可读
- 槽位表达明确，能够快速识别前线、能量线与资源区
- 装饰压低，避免重纹样、重材质、重粒子干扰读牌
- 保持实体卡桌的区域逻辑感，同时适配屏幕显示与高频操作
- 让背景保留“正式比赛桌垫”的舞台感，但不压过卡牌与交互信息

标准场景基底按当前项目版面组织：

- 上部为敌我镜像战场
- 中部为主战场可视区与局部信息区
- 左侧为预览辅助区
- 右侧为日志或辅助信息区
- 底部为手牌与主操作条

## 2. 风格关键词

- Competitive card table mat
- Dark red
- Clean slots
- High contrast
- Minimal decoration
- Digital tabletop
- Structured battlefield
- Tactical readability
- Compact and professional
- Strong zoning
- Printed playmat translated to screen

风格禁忌：

- 不使用大型二次元手游大厅式发光面板
- 不使用厚重金属浮雕、复古羊皮纸、写实皮革等强材质方向
- 不使用高饱和霓虹堆叠，避免红紫蓝同时争抢注意力
- 不使用大面积复杂粒子流、火焰、雷电特效作为常驻背景
- 不使用过多拟物按钮或卡牌外框装饰件
- 不把所有区域都做成厚重独立面板，避免丢失“桌垫式战场”整体感

## 4. 战场背景方案

### 4.1 全局背景结构

背景分为四层：

1. 底层纯色：`#0F1115`
2. 中层大面积红黑渐变：从 `#4B1118` 过渡到 `#171A21`
3. 战场桌垫层：以 `#9E1F2B`、`#B92B37`、`#7E1822` 做低对比分布
4. 局部线框、暗角与极轻量光斑层

### 4.2 渐变与聚焦建议

- 主渐变方向：由左上至右下的深红过渡
- 中心聚焦区：战场中轴横向 58% 宽度范围内亮度提升 `8%`
- 左右边缘允许出现桌垫式高光切面，但透明度不得超过 `18%`
- 两侧边缘压暗：左右各 `12%` 宽度加入 `#0B0D11` 的透明遮罩，透明度 `36%`
- 上下暗角：透明黑覆盖 `16%`

### 4.3 底纹建议

背景允许保留参考图中的几何折线与细发光节点，但必须压低到辅助层，只作为“竞技桌垫的舞台感”存在：

- 折线颜色：`rgba(255,240,240,0.20)`
- 线宽：`1 px`
- 节点光点直径：`4-6 px`
- 节点发光半径：`10-14 px`
- 整体装饰层透明度上限：`14%`
- 禁止使用高反差蜂巢、重网格、复杂符文
- 禁止让装饰线穿透区域标题与关键数值文本

### 4.4 战场区域底盘

- 战场主底盘宽度建议占内容区 `74%`
- 外轮廓圆角：`20 px`
- 外描边：`1 px solid rgba(255,255,255,0.08)`
- 内发光：`0 0 28 px rgba(200,58,58,0.10)`
- 内阴影：`inset 0 0 0 1 px rgba(255,255,255,0.03)`
- 视觉感觉应更接近一整张桌垫上的印刷分区，而不是多个独立浮起的重面板

## 6. 卡槽 Slot 规范

### 6.1 基础槽位

- 标准槽位底色：`rgba(255,255,255,0.03)`
- 标准槽位描边：`2 px solid rgba(244,233,229,0.78)`
- 圆角：`10 px`
- 内阴影：`inset 0 0 0 1 px rgba(255,255,255,0.03)`
- 外阴影：`0 6 px 16 px rgba(0,0,0,0.18)`

### 6.2 空槽表达

- 空槽内使用低对比中轴标记或轻微面积压暗
- 中心辅助线颜色：`rgba(244,233,229,0.18)`
- 中心标识透明度：`18%`
- 禁止使用大号 “+” 号或高亮虚线框破坏桌垫式一体感

### 6.3 悬停态

- 底色提亮 `4%`
- 描边切换为 `#FFFFFF`
- 外发光：`0 0 12 px rgba(255,255,255,0.14)`

### 6.4 选中态

- 描边：`2 px solid #F5C542`
- 外发光：`0 0 18 px rgba(245,197,66,0.22)`
- 内部遮罩：`rgba(245,197,66,0.06)`

### 6.5 不可用态

- 槽位整体明度降低 `18%`
- 边框变为 `#2D323B`
- 内容透明度降至 `62%`

### 6.6 特殊槽位区分

- FRONT LINE 槽位：允许使用红色微弱底托，厚度 `3 px`
- ENERGY LINE 槽位：允许使用浅白红底托，厚度 `2 px`
- AP 槽位：允许使用金色环形内框，厚度 `2 px`

## 12. 动效建议

### 12.1 总体原则

- 动效服务于信息确认，不服务于装饰炫技
- 速度偏快、节奏干净、停留明确
- 常驻动效极少，避免视觉疲劳

### 12.2 时长建议

- 悬停淡入：`120 ms`
- 选中强调：`160 ms`
- 面板展开：`180 ms`
- Tooltip 淡入：`100 ms`
- 区域高亮呼吸：`1600 ms` 一个完整周期

### 12.3 动效类型

- 卡槽悬停：轻微描边增强 + `2 px` 上浮错觉
- 卡牌选中：`1.03` 倍放大 + 金色描边点亮
- 区域聚焦：标题条亮度提升 `12%`
- 预览联动：蓝色或金色细描边扫光一次，持续 `180 ms`
- 计数变化：数字轻微缩放 `1.08 -> 1.00`

### 12.4 禁止方向

- 禁止大面积火花粒子、能量波纹、连续闪屏
- 禁止高频震动或长时间漂浮动画
- 禁止多个区域同时强脉冲

## 14. 最终视觉原则总结

- 所有视觉决策以“分区清晰、槽位明确、信息优先”为最高原则
- FRONT LINE、ENERGY LINE、AP AREA 必须形成明显层级递进，不得视觉等权
- LIFE 与 DECK 负责稳定识别，OUTSIDE 与 REMOVED 负责弱化承载，但都必须边界清楚
- 红黑是主轴，背景允许保留桌垫式亮红切面，但信息层必须压住背景层
- 区域表达优先采用“桌垫印刷分区 + 轻量数字承托”的混合方案，而不是纯线稿或纯重面板
- 常态界面以深色、低噪声、高对比为准，不靠复杂材质与粒子制造质感
- 卡槽、卡牌、按钮、图标、面板应共享同一套圆角、描边、阴影与高亮规则
- 任何新增素材都应优先判断是否符合本规范中的色彩、结构、对比与命名基线，避免局部风格漂移
