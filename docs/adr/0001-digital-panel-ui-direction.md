# 视觉方向：桌垫印刷分区 → 独立数字面板

2026-06-08 决定将 TcgDemo 战场 UI 从"竞技桌垫印刷分区"方向全面转为"独立数字面板"方向，
参考 Yu-Gi-Oh! Master Duel 的冷蓝黑赛博竞技场视觉语言。

## 为什么翻

旧规范 (`ui_art_style_guide.md`, 2026-03-30) 定义了以 1008×1024 红色竞技桌垫图为
视觉锚点的方向：所有区域是"同一张垫子上的印刷分区"，坐标按背景图比例映射。
两个月后该方向的不足已明确：

- 桌垫印刷分区在屏幕上的区域识别度弱——四个面板挤在背景图上，靠线框区分
- 色板基于"实体卡店红黑桌布"推导，偏暖偏重，适配屏幕显示时缺乏层次
- `ZoneLayoutConfig` 依赖背景图尺寸做绝对坐标映射，扩展性差
- 手牌与主要区域之间的纵向间距不足

## 新方向

独立数字面板 + Master Duel 式冷蓝黑赛博基底：

- 四行镜像面板（敌能量→敌前线→我前线→我能线），每行是独立 UI 模块
- 深蓝黑底色 (`#0A0E17`) + 半透明深蓝灰面板 (`rgba(20,26,36,0.88)`) + 青色/暗金强调
- 1440p 设计基准，1080p 降级适配
- 所有卫星区（LIFE/DECK/OUTSIDE/REMOVED）退化为紧凑附属堆叠
- AP 退化为顶部 HUD 数字计数器
- 纯色渐变背景，不再依赖 `battle_bg.jpg`
- 前线/能量线等权，同形异色（暖红/冷蓝标题条）

## 考虑的备选

- **继续打磨桌垫方向**（否决）：旧规范纸面合理但不适合屏幕，继续投入属于优化错误方向
- **从零做纯扁平数字原生 UI**（否决）：太远，可用 MD 做参照加速设计收敛

## 后果

- `ZoneLayoutConfig` 基于背景图的坐标映射退役
- `ui_art_style_guide.md` 需要全文重写
- 色板从暖红黑体系全面转到冷蓝黑体系
- 所有 UI 文件需要在新 Theme 体系下重新组织
- 设计基准改 1440p，测试需覆盖多分辨率
